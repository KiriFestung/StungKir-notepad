# Заметки для Claude (как работать с этим проектом)

StungKir - писательский блокнот KiriFesTung: PySide6 (Linux, Windows) + приложение для Android (Kotlin, Compose, папка `android/`). GPL-3.0-or-later, Claude указан в AUTHORS.md.

## Правила
- Отвечать по-русски, просто и прямо.
- Длинное тире «—» только в начале реплики (строки); внутри текста - короткое «-». Касается и текстов интерфейса, и документации.
- Никаких имён из мира автора в программе, примерах и тестах. Только нейтральные: Тервена, Давнь, Кев, Лосс, Ния, Кира, Мира.
- Шрифт текста по умолчанию - обычной насыщенности.
- Не писать в репозиторий личные данные автора (почту, настоящее имя, адрес).

## Проверки
- Вся программа: `QT_QPA_PLATFORM=offscreen python3 -m stungkir --test` (больше 330 проверок). Новый модуль проверок - добавить в `stungkir/tests/run.py` (MODULES).
- Обязательно и на PySide 6.8 (на нём Flatpak): `pip install "PySide6==6.8.2.1"` в отдельном venv и тот же запуск. На 6.8 у списков `widget.update()` - это `update(index)`, нужен `QWidget.update(widget)`.
- Роботы: `MONKEY_STEPS=2500 MONKEY_SEED=N python3 -m unittest stungkir.tests.test_monkey`, `FUZZ_STEPS/FUZZ_SEED` для test_fuzz.
- Android, логика без Android SDK: `android/app/src/main/java/.../logic/*.kt` и проверки в `android/app/src/test`. Полная сборка - только в GitHub Actions (`.github/workflows/android.yml`).
- Тексты в проверках писать с `encoding="utf-8", newline="\n"` (иначе на Windows cp1252 и `\r\n`).
- `ruff check stungkir` должен быть чистым.

## Сборки (GitHub Actions)
- `check.yml`: проверки на Linux (PySide 6.8 и новый), на Windows - сборка, проверка готовой сборки, установщик и переносная версия; кладёт их в релиз `windows-latest`. Ещё снимает окна готовой сборки на Windows (`StungKir.exe --screens <папка>`, код - `stungkir/tests/screens.py`) в артефакт `StungKir-Windows-screens` - так видно вид на Windows без Windows.
- `android.yml`: проверки и APK, релиз `android-latest`. Подпись: `android/app/stungkir-release.keystore`, пароль - секрет `ANDROID_KEYSTORE_PASSWORD` (есть только у автора). Без секрета APK в релиз не выкладывается. Сменить ключ - `new-key.yml` (кнопкой, после смены секрета), шаги в docs/ТЕЛЕФОН.md.
- `build.yml`: Flatpak (KDE 6.8), сам при изменениях программы и по кнопке; релиз `linux-latest`.
- `robots.yml`: каждую ночь обезьяна и фаззер с новым зерном (около 10 минут). Нашли ошибку - задача «Роботы нашли ошибку» (метка «роботы») с зерном и командой повтора.
- `release.yml`: выпуск «StungKir X.Y.Z» кнопкой - когда три «свежие сборки» собраны из того же коммита main. Номер версии - в `stungkir/__init__.py`, `pyproject.toml`, `installer.iss`, metainfo Flatpak, первом разделе CHANGELOG и ссылке на установщик в README (проверка `VersionTest` следит, чтобы совпадали); у Android свои `versionCode`/`versionName`.
- Журналы Actions из сессии Claude не скачиваются: ошибки шагов выводятся заметками (`::error::`), их видно через API check-runs/annotations.
- `packaging/windows/build-windows.ps1` - в UTF-8 с BOM (иначе PowerShell 5 ломает русский текст).

## Устройство (коротко)
- Код по папкам: `stungkir/core` (настройки, диск, защита, корзина, снимки), `text` (редактор и инструменты правки), `world` (справочник, хронология, кто в какой главе), `story` (план, доски, таблицы), `books` (сборка, импорт, обложки, сайт, пример), `fun` (кубики, рулетка, антистресс, звуки), `ui` (главное окно и его части-примеси, диалоги, стили). Наверху - только `app.py` и `__main__.py`; картинки, шрифты, звуки - в `stungkir/art`, `fonts`, `sounds` (из подпапок путь - `Path(__file__).resolve().parents[1]`).
- Язык интерфейса: в коде надписи русские, на экран - через `tr()` из `core/i18n.py`; английский словарь - `core/lang_en.py` (нет перевода - остаётся русский). Данные в файлах (статусы плана, шаблоны и т.п.) не переводить - только показ. Английский - два варианта: `en` (US) и `en-GB` (UK = US + британское написание из `i18n.BRITISH`). Формы слова - `textutil.plural` с английскими парами из `i18n.PLURALS`. Выпадающие списки, значения которых хранятся, - `addItem(tr(x), x)` и `currentData()`. Язык выбирается при первом запуске (`app.choose_language_once`, установщик Windows передаёт свой выбор через `installer_language`) и в «Настройках», меняется после перезапуска. Телефон пока только по-русски.
- Английский текст (по абзацу, не по языку интерфейса: в абзаце нет русских букв): реплики в кавычках “…” "…" ‘…’ - `textutil.quoted_spans`; орфография латиницы - `Speller.ok_english` (словари `packaging/dictionaries/en_US`, `en_GB`, выбор по языку интерфейса); «кто говорит» - `speakers.quoted_segments` и she/he/I; повторы и «мои штампы» - по основе `textutil.english_root` (looked = looks = looking), служебные слова - `ENGLISH_STOP_WORDS`; имена персонажей можно латиницей. Русские абзацы - строго как раньше.
- Тексты: `~/StungKir/<категория>/<глава>.txt`, порядок - `.order` (JSON-список), служебное - `~/StungKir/.stungkir/` (версии `versions/<категория>/<файл>/<время>.txt`, до 50; `stats.json` компьютера, `stats-phone.json` телефона - складываются; `days.json`, `names.json`).
- Зашифрованный файл начинается с `STUNGKIR-ENC1\n` (scrypt + Fernet). Телефон пароль пока не умеет.
- Переносная версия: `portable.txt` рядом с `StungKir.exe` - тексты, данные и настройки рядом с программой.
- Картинки кубиков автора: `stungkir/art/dice/<материал>/d<N>.png` (bone, metal, oak, resin = «Индиго»).

## Картинки и анимации (редизайн)
- Всё перерисовывается программами в `packaging/`: фактуры бумаги, льна, сукна и пробки - `textures/`; камни, «блинчик», грабли сада - `blender/garden.py`; монетка-чеканка - `blender/coin.py` (свет - HDRI с Poly Haven через `blender/hdri.py`, кэш `~/.cache/stungkir-hdri`); кубики - `blender/dice.py`; бег и прыжок ласки - `anim/weasel.py` (гнёт рисунок автора, лапы дорисовывает), объём ласки - `anim/polish.py`, огонёк серии - `anim/flame.py`; копии иконки (ICO, SVG Flatpak, значки Android) - `icons.py`.
- Blender - 4.2 с blender.org (в сборках Debian/Ubuntu нет шумодава). Запуск: `blender -b -P <скрипт> -- <аргументы>` (аргументы - в начале скрипта).
- Исходные плоские рисунки автора - `packaging/art-src/` (ласка, монетки): программы берут их оттуда, их не перезаписывать.
- Решения автора: иконку программы и карточки «О программе» не трогать (3D иконке не нужно, новые формы иконки не подошли). Любую картинку - сначала проба «было/стало» картинкой автору, вставлять только после «да».
- Опыт: студийная HDRI хороша для металла и эмали, матовым камням вредит (съедает объём). Рисовать персонажей с нуля кодом выходит плохо - лучше гнуть/дорабатывать рисунок автора.
- Дальше (по желанию автора, каждое - пробой): пупырка (полиэтилен с бликами), барабаны «Рулетки» (металл, дерево, гравировка), тумблеры (хром), мячик. Если подключён Blender MCP - можно работать прямо в сцене автора и генерировать 3D по картинке.
- Картинки в `stungkir/art/` проверяются `stungkir/tests/test_animation.py` (число кадров, наличие); меняешь число кадров - поправь там.
