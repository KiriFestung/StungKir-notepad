# StungKir на телефоне (Android)

Отдельное приложение, которое работает с той же папкой `StungKir`, что и блокнот на компьютере. Между устройствами папку возит **Syncthing** - по Wi-Fi дома или через интернет, без облаков и аккаунтов.

## Что умеет (версия 0.1)

- Категории и главы - в том же порядке, что на компьютере (`.order`).
- Редактор с подсветкой как на компьютере: реплики, знаки препинания, `*курсив*`, `**жирный**`, `[пометки]`, заголовки `#`, повторы слов рядом. Проверка орфографии - от клавиатуры телефона.
- Кнопки над клавиатурой: отмена и повтор, тире реплики, «ёлочки», многоточие, курсив, жирный, пометка, заголовок, разрыв сцены.
- Вставка из буфера чинится так же, как на компьютере: слипшиеся абзацы разрезаются.
- Автосохранение: через полторы секунды тишины, при выходе из главы и когда приложение уходит в фон.
- Версии главы (`.stungkir/versions`, тот же формат и те же 50 штук): появляются сами раз в 10 минут, при выходе и перед первым изменением; любую можно вернуть.
- Если Syncthing привёз новый текст с компьютера - глава обновится сама. Если правили на обоих сразу - на экране остаётся текст телефона, а пришедший ложится в «Версии».
- Удалить главу: долго держи её в списке или в главе нажми ⋮ → «Удалить главу…». Она уходит в корзину - ту же, что на компьютере («Ещё» → «Файлы и импорт» → «Корзина»), и 30 дней её можно вернуть вместе с версиями.
- Длинную главу можно «бросить» быстрым свайпом - текст прокатится сам, касание его останавливает.
- Копии-конфликты Syncthing (`*.sync-conflict-*`) видны с жёлтым значком: можно сравнить и выбрать, какую оставить. Вторая уходит в «Версии».
- Слова за день, цель, серия. Телефон пишет свои числа в `.stungkir/stats-phone.json`, компьютер - в `stats.json`; оба устройства их складывают, поэтому «сегодня» и серия общие. Вставленное из буфера не считается.
- Десять тем - те же, что на компьютере. Шрифты Literata и PT Serif, размер, межстрочный, «не гасить экран».

Пока **нет**: пароля (главы под паролем видны с замком - их открывай на компьютере), таблиц, досок и лент времени, поиска, персонажей, чтения вслух, кубиков. Это потом.

## Как поставить

1. Скачай `StungKir-Android.apk` со страницы проекта на GitHub: **Releases → «StungKir для Android - свежая сборка»**. Она обновляется сама после каждого изменения. Пока репозиторий закрытый, для этого нужно войти в GitHub в браузере телефона.
2. Открой apk на телефоне. Android спросит, можно ли ставить приложения из этого источника (браузера или файлового менеджера) - разреши.
3. Новую сборку ставь поверх старой: все сборки подписаны одним ключом, настройки и всё остальное сохраняются.

## Как связать с компьютером через Syncthing

Syncthing - бесплатная программа, которая сама копирует папку между твоими устройствами напрямую, без облаков. Ставится по разу на компьютер и на телефон.

### 1. Поставь Syncthing на компьютер

**Linux (Debian, Ubuntu):**
```
sudo apt install syncthing
syncthing
```
Откроется страница в браузере `http://127.0.0.1:8384` - это и есть Syncthing. Чтобы он запускался сам: `systemctl --user enable --now syncthing`.

**Windows:**
1. Скачай установщик с https://syncthing.net/downloads/ - пункт «Windows», вариант с установщиком (Syncthing Windows Setup). Он сам запускается вместе с Windows и сидит значком у часов.
2. После установки открой в браузере `http://127.0.0.1:8384` (или двойной щелчок по значку у часов).
3. Если Windows спросит про доступ к сети («Брандмауэр Защитника Windows») - разреши для **частных** сетей, иначе телефон не увидит компьютер.

Папка с текстами на Windows: `C:\Users\<твоё имя>\StungKir` (у переносной версии с флешки - папка `StungKir` рядом с `StungKir.exe`; её с телефоном лучше не связывать: флешку вынимают, и Syncthing теряет папку).

### 2. Поставь Syncthing на телефон
Приложение **Syncthing-Fork** (F-Droid или Google Play). Открой, разреши уведомления и доступ к файлам.

### 3. Свяжи устройства
1. На компьютере, на странице Syncthing: «Действия» (справа вверху) → «Показать ID» - появится QR-код.
2. На телефоне в Syncthing-Fork: вкладка «Устройства» → «+» → значок QR-кода у поля ID → наведи камеру на экран компьютера. Имя - например «Компьютер» → сохранить (галочка).
3. На компьютере появится вопрос «Устройство … хочет подключиться» - нажми «Добавить устройство» → «Сохранить».

### 4. Открой папку с текстами для телефона
1. На компьютере: «+ Добавить папку». Путь: на Linux `~/StungKir`, на Windows `C:\Users\<имя>\StungKir`. На вкладке «Общий доступ» отметь телефон → «Сохранить».
2. На телефоне придёт вопрос про новую папку - прими её и выбери, куда положить, например `/storage/emulated/0/StungKir`.
3. Подожди, пока обе стороны покажут «Синхронизировано».

### 5. Запусти StungKir на телефоне
Разреши «Доступ ко всем файлам» и выбери найденную папку StungKir.

Дальше пиши где удобно. Совет: перед тем как сесть за главу на другом устройстве, дай Syncthing пару секунд досинхронизировать - тогда конфликтов почти не будет. Компьютер и телефон должны быть в одной сети Wi-Fi или оба в интернете - Syncthing найдёт дорогу сам.

## Сборка из исходников

Проект лежит в папке `android/` (Kotlin, Jetpack Compose). Нужны JDK 17 и Android SDK:

```
cd android
gradle testDebugUnitTest assembleDebug
```

Готовый файл: `android/app/build/outputs/apk/release/app-release.apk`. Проверки логики (порядок, версии, статистика, подсветка, вставка, отмена) - в `android/app/src/test`.

Подпись: ключ `android/app/stungkir-release.keystore` зашифрован паролем, пароль хранится только в секретах GitHub (`ANDROID_KEYSTORE_PASSWORD`) и у автора. Без пароля сборка подписывается отладочным ключом: для своих проверок годится, но поверх версии из «Релизов» не встанет.
