# StungKir - задание для дизайна

Это задание для дизайнера (или Claude Design) от разработчика StungKir. Готовые файлы KiriFesTung присылает разработчику в zip, разложенными по папкам, как в таблице ниже. Разработчик подгоняет их, вставляет в программу и проверяет.

## Что за программа
StungKir - писательский блокнот для длинных текстов (книги, миры), Linux, Windows и Android. Тёмный, спокойный, «вечерний» вид: в нём пишут часами.

## Стиль
- Палитра основной темы «Индиго и охра»:
  - фон `#121429`, панели `#181b37`, рамки `#282c55`;
  - текст `#c6cbe9`, приглушённый `#6a6f9c`;
  - охра (акцент, золото) `#d4a02e` / `#e8a93a`;
  - индиго (тела предметов) `#2a2696`, тёмное `#07073a`.
- Светлая дневная тема «Дневная бумага»: фон `#f3ecdb`, текст `#3b342b`. Всё, что лежит поверх фона, должно смотреться и на тёмном, и на светлом фоне.
- Шрифты: Literata (заголовки, книжный текст), PT Serif. Других шрифтов в картинках не нужно.
- Предметы - объёмные рендеры в духе уже готовых кубиков (`stungkir/art/dice/`): мягкий свет слева сверху, лёгкий блик, без резких теней на фон.
- Персонаж - ласка KiriFesTung (`stungkir/art/app-icon.png`, `weasel.png`). Её можно ставить в сценки, но не перерисовывать в другой стиль. Второй персонаж - ворон (сторона монетки).
- Без чужих логотипов, персонажей и шрифтов. Без текста на картинках, кроме названия «StungKir».

## Что уже сделано (менять не надо)
Кубики d4-d100 в четырёх материалах, мячик, пупырка (целая и лопнутая), булавки, пробка, сукно, бумага и лён, «пустой лист», «О программе», шапка для GitHub (`docs/banner.png`).

## Что нужно

Все файлы - PNG с прозрачным фоном, если не сказано другое. Размер - не меньше указанного: уменьшит разработчик.

| Файл | Размер | Что | Важно |
|---|---|---|---|
| `art/coin-heads.png` | 512×512 | монетка, сторона «Ворон» | строго анфас, идеальный круг по центру; обе стороны одного диаметра; золото/охра |
| `art/coin-tails.png` | 512×512 | монетка, сторона «Ласка» | то же |
| `art/drum.png` | 480×480 | барабан револьвера для «Рулетки» | вид строго сверху, ось - в центре картинки, 6 гнёзд ровно через 60°, первое - сверху. Гнёзда пустые: патроны рисуются отдельно |
| `art/round-live.png` | 160×160 | патрон, вид на донце | по центру; латунь с капсюлем |

| `github/screens/*.png` | любые | красивые подложки или рамки для снимков экрана | по желанию |

## Как прислать
Один zip, внутри папки `art/`, `android/`, `github/` с файлами под этими именами. Если что-то не готово - просто не клади, остальное встанет.
